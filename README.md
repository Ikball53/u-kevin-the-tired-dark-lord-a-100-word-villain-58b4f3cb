## The Tired Dark Lord: A 100-Word Villain Monologue

A 98-word monologue, 516 characters: the Lord of Westmere tells the heroes to sit — the floor is cold, his knees are older than the throne, and the cursed harvest is stalled on Form seven-B, signed in triplicate, because the crows refuse to file it. Come back Thursday. He will be — ah — almost ready.

`main.py` writes the exact line (no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

Run it with:

